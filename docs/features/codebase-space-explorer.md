# Feature: Codebase Space Explorer (project concept)

## Status
Research: friction audit in progress (4 scouts, spawned 2026-11-03).

## Trigger
The user's words, 2026-11-03:
> "a gamified github codebase space explorer. The more high quality CRs you draft, the more your astronaut character will see of the world. You slowly discover over time spent working. In collaborative mode … you can see their astronaut characters too. 3D.js art-wise, but with a pixel renderer over the top. The planets will be procedurally generated. I want to basically make the project software-factory related as well as using a software-factory to build it. … see what each team member has worked on at what time which allows you to determine the POC for certain features … applied to existing codebases where it builds out the planetary system for you and reviews each 'astronaut' or team member. … the app doesn't seem overly useful now and I can't think of the one USP. Target: intermediate to senior software engineers."

## Requirements (draft; the USP is not chosen yet)
- [ ] Import an existing GitHub repo and generate a procedural planetary system from its structure and history.
- [ ] Each contributor appears as an astronaut. Collaborative mode shows teammates.
- [ ] Exploration (fog of war) is gated by PR quality.
- [ ] Find a point of contact (POC): who worked on what, and when.
- [ ] Render in three.js with a pixel-art post-process.
- [ ] **One USP grounded in a top-ranked friction point for intermediate and senior engineers.** Blocking.

## Assumptions (open)
- [ ] LOAD-BEARING: there is a definition of "high-quality PR" that resists gaming and doesn't feel like surveillance.
- [ ] LOAD-BEARING: senior engineers would come back to a visual, gamified explorer, despite the visualisation graveyard (CodeSee, Sourcetrail).
- [ ] GitHub history can be ingested within rate limits for a real repo.
- [ ] Per-person "reviews" of astronauts won't trigger distrust.

## Research
- Scouts: (1) friction-evidence audit, (2) landscape and graveyard, (3) practitioner voice, (4) PR-quality measurement and data.
