# Fog lab measures

Generated by `node lab.mjs measures` (or `node lab.mjs report` from measures.json). Every number in the README is here. Colour distances are OKLab (0.02 is about one just-noticeable difference); GLANCE = 0.05 is health-looks' "at a glance" floor.

## F1 · per file, on #18's grid

Every planet pixel's shader cell (the `ids` render) against #18's `fibonacciCell` grid computed on the CPU for the same pixel (camera ray, sphere hit, the surface's own frame). A boundary pixel is one whose shader cell is within 0.01 rad of as near as the nearest (an edge, or a corner where three cells meet: the mesh is faceted); limb pixels are grazing rays (within 17° of the surface), where the facets sit farthest off the sphere. Owner: the file the cell's fog belongs to; fogged: the cell's state against the mock's fog view.

## F3 · health reads through fog

health-looks' classifier, read-only: each disc's look vector `[L, a, b, C, Lsd, edge, glow]` (`metrics.mjs` `measure()`, with the glow sentinel for lava) is read as the band of the nearest **clear** look centroid (24 seeds per look, the lab's own clear renders). A read is **confusable** when another band's look is within GLANCE. The **vote** is the debris lab's per-pixel classifier: each disc pixel votes for the band whose clear discs hold the nearest colour; the share for the planet's own band. Fogged: seeds 1–8 per look (the layout seed follows the terrain seed).

**Fidelity:** the lab's clear hero renders against health-looks' measurements.csv (hero, normal vision): 144 look × seed pairs, largest difference in any look-vector statistic or pixel count 0.0000500 (lava 19 L).
